# AGENTS.md

DevMuse's maintainer contract has one home: **[CLAUDE.md](./CLAUDE.md)**. Read it
first — its documentation-sync rules, canonical-home map, and "skills are code"
discipline apply to every agent working in this repository, not only Claude Code.
This file is a pointer, not a second copy, so the contract cannot drift between
two files.

## For Codex and other non-Claude hosts

- The generated host policy lives in
  [`adapters/codex/HOST_POLICY.md`](./adapters/codex/HOST_POLICY.md) — including
  the opt-in concurrent-subagent-dispatch guidance. It is generated by
  `npm run build:adapters`; never hand-edit `adapters/codex/**`.
- Canonical skills, knowledge, and runtime live under `plugin/`. The Codex
  adapter is vendored from them and verified drift-free by
  `npm run test:generated`.
