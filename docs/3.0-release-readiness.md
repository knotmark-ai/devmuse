## Per-issue backlog

### #62 GitHub-first project context — *green but shallow*
The decision core (identity/manifest/capability/authorization/managed-blocks/delivery projector) is solid and well unit-tested. Gaps:
- **S1** Worktree-resume pointers have a reader but **no writer** — no skill calls `update-cache` for `issue`/`pull_request`/`pipeline_phase`, so those fields are dead; UC-G8/UC-G9 undemonstrated, no cross-worktree round-trip test. `resolver.mjs:127,141-143`.
- **S1** The `github-first-contract` behavioral prompts (`prompts/*.txt`) are **inert** — no runner reads them; the suite is 100% string-match. `tests/github-first-contract/run-test.mjs`.
- **S2** UC scenario map (`scenarios.mjs`) runs only under `--scenario`, never in CI (`run-scenario.mjs:8-24`); `update-cache` CLI path untested; `reconcileCacheEntry` not exposed via CLI (UC-G9 dead end).
- **S3** `acquireLock` **drops the current write** on a stale lock instead of retrying (comment promises a retry the code never does). `cache.mjs:231-233`. Dead exports `upsertRecoveryAttempt`/`clearRecoveryAttempt`.

### #63 living, profile-based PRD & architecture — *foundation + cosmetic slice*

- **B(63)-2** Profile composition **unwired**: mu-prd still hardcodes the 9-section "full mode"; stages 2-3 changed ~15 lines; no PRD template; output still dated `docs/prd/…`, not `artifacts.prd`. `mu-prd/SKILL.md:122-139,155-161`.

### #44 model-churn routine — *borderline, one correctness gap*
- **H2** `run-all.sh` can silently judge a **stale transcript from a prior model** — it passes no transcript path, so `judge.sh` auto-selects the newest by mtime; a run that produced no fresh transcript is graded against an old one, corrupting the model-churn signal. `run-all.sh:30-31`, `run-test.sh:45`. (Exit aggregation and the earlier pipe-masking are correctly fixed.)
- **Consequence:** the "9/9 Fable 5 PASS" recorded for #44 is not fully trustworthy until B5/H1/H2 are fixed and the sweep is re-run.
